## LiberRPA

> Production automation is software. Build it like software.

LiberRPA combines visual process design with ordinary Python, aiming to bring conventional software-engineering practices into RPA development.

The toolchain includes:

- visual Flow Projects with Python-based implementation;
- Windows UI, browser/DOM and image-based automation;
- reusable Components packaged as Python Wheels;
- PEP 440 dependency resolution and exact dependency locking;
- integrated Editor, Project Manager, Snippets Tree and UI Analyzer tooling;
- local execution, runtime diagnostics and structured logging.

Version **0.3.0** is now available.
